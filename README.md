Career Twin Project

Create Python Virtual Environment
python -m venv jims_env

Mac:
source jims_env/bin/activate

Windows:
jims_env\Scripts\activate

Mandatory Steps:
1. Install Gemini SDK
pip install -U google-genai

2. Verify if package installed successfully
pip show google-genai

3. Install dotenv package for loading environment variables
pip install python-dotenv
